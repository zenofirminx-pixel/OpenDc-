# Photographies OpenDC

La galerie de connexion utilise des photographies de personnes réelles hébergées par Unsplash.
Elles sont chargées depuis Unsplash au moment où la page s’affiche ; une connexion Internet est donc nécessaire pour les voir.

Les anciennes illustrations SVG de galerie sont conservées dans public/assets pour ne pas supprimer de fichiers sans nécessité, mais le composant de galerie ne les utilise plus.
